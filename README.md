# Student Attendance Management System

A web-based Attendance Management System built using Flask, HTML, CSS, JavaScript, and SQLite.

## 🚀 Live Demo

https://student-attendance-management-system-2gfa.onrender.com

## ✨ Features

- Student Registration
- Mark Attendance
- Prevent Duplicate Attendance
- Attendance Report
- Attendance Percentage
- Delete Student
- Dashboard

## 🛠 Technologies Used

- Python
- Flask
- HTML
- CSS
- JavaScript
- SQLite
